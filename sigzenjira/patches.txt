# This app has NO `fixtures` hook - nothing is re-applied automatically on
# migrate. Every customization is declared in Python (custom_field.py,
# property_setter.py, custom_permission.py, dashboard/pm_dashboard.py,
# setup.py), created on a fresh site by setup.py:after_install, and pushed to
# already-installed sites by a patch listed below. One patch per change:
# add/edit the declaration, then add a patch that applies just that change.
#
# So everything belongs here - Custom Field, Property Setter, Custom DocPerm,
# Report, Number Card, Dashboard Chart, Dashboard, Notification, Workflow,
# Workspace - plus data migrations (backfill/transform) and deletions.
#
# Patches are recorded in `Patch Log` and run exactly once per site, so a patch
# must stay idempotent but will not re-run to pick up a later edit to the dict
# it reads. Change the dict again, ship another patch.
